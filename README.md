# 拾游 v1.0.0

拾游是一个供个人使用的 Windows 桌面游戏攻略资料库。它把游戏分区、视频和文字攻略、本地资源、收藏及版本记录放在同一个应用里，资料保存在当前电脑，不需要注册或登录账号。

## 获取并启动

### 使用桌面版

v1.0.0 提供 Windows x64 便携版：将发布页提供的 ZIP 压缩包完整解压到电脑上的文件夹，然后双击其中的 `拾游.exe`。无需运行安装向导；请保留解压出的整个应用文件夹，不要只移动 exe 文件。

应用数据保存在当前 Windows 用户的 `%APPDATA%\拾游` 目录。删除或移动应用程序文件夹不会自动搬迁这份数据；清理该目录会删除应用资料，因此请先导出备份。

### 从项目源码启动或构建

在项目目录双击 `启动拾游.bat`。如果已有桌面版构建文件，它会打开 `release\拾游-win32-x64\拾游.exe`；否则会启动本机服务并在默认浏览器打开 `http://127.0.0.1:8765`。本机服务只监听回环地址，不向局域网开放。

要自行构建桌面版，需要安装 Node.js 24 或更新的 LTS 版本，并确保可以下载 npm 依赖和 Electron 运行时。随后双击 `构建拾游软件.bat`，构建完成后运行 `release\拾游-win32-x64\拾游.exe`。构建脚本首次运行需要联网下载构建依赖。

桌面版和浏览器版使用不同的本地资料存储。若从浏览器版切换到桌面版，或改用另一个浏览器/运行来源，请先在原版本导出完整备份，再在新版本导入。

## v1.0.0 功能

- **首页总览**：在首页搜索游戏、攻略、视频、分类、标签和笔记，结果可直接打开相应分区或资料；查看本地统计、我的游戏、本地热点和最近整理内容。首页热点及版本摘要来自本地资料，不会自动联网更新。
- **游戏分区**：按游戏归档资料；新建、编辑、删除分区；设置当前版本、描述、整理进度和自定义背景图。背景图支持 JPG、PNG、WebP，单张原图最大 10 MB，保存时会压缩并随完整备份保存。
- **视频攻略**：登记视频标题、游戏、链接、作者、时长及个人笔记/关键时间点。对哔哩哔哩公开视频，可主动点击“自动识别信息”联网读取标题、作者、时长和来源；不点击时不会为识别而联网。支持的哔哩哔哩视频在应用详情中内嵌播放，直接视频文件链接可用内置媒体播放器播放；其他网页链接仅作为资料索引，不会在应用内播放。
- **文字攻略**：按游戏和分类编写、查看、搜索及维护个人攻略笔记。
- **资源下载**：登记资源名称、游戏、类型和说明。可选择文件导入并由拾游托管到本机资料库，之后可从应用下载，且会进入完整备份；也可只登记现有本机路径或网页链接。仅登记路径/链接不会复制或托管对应文件。
- **收藏夹**：集中查看收藏的视频、文字攻略和资源；收藏指向原资料，取消收藏不会删除原资料。
- **版本预览**：按游戏记录版本号、日期、改动主题、摘要、标签和“待体验/已整理”状态。记录可在首页作为本地热点或版本摘要入口。
- **数据与设置**：导出/导入完整备份，清空并恢复初始示例资料，切换紧凑显示。清空操作会删除当前资料和已导入文件，并有确认步骤。

项目首次启动时会显示示例游戏及资料，示例内容可编辑或删除。应用不抓取新闻或版本公告，热点和版本记录需要自行整理。

## 常用操作

### 搜索资料

在首页顶部搜索框输入游戏名（例如“原神”）或攻略标题、分类、标签、笔记关键词。下拉结果会列出相关游戏分区、视频、文字攻略、资源和版本记录，点击结果可打开对应内容。

### 录入哔哩哔哩视频

进入“视频攻略”，新增视频并粘贴哔哩哔哩公开视频链接，点击“自动识别信息”。识别到的标题、作者、时长和来源会填入表单；保存前可自行修改。识别需要联网，失败时可以手动填写。视频来源链接用于识别和生成播放器，播放在应用详情中完成。

### 管理本地资源

进入“资源下载”并选择“登记资源”。若希望文件由拾游保存并能随备份恢复，在表单中选择“导入文件到拾游本地资料库”；若只填写路径或链接，则只保存索引。已托管文件可通过资源条目上的打开/下载操作取回。

### 导出备份和恢复

1. 打开“数据与设置”，点击“导出资料库”。
2. 将下载得到的 `拾游完整备份-日期.json` 保存到电脑上安全的位置；备份包含结构化资料、偏好设置、分区背景图和已托管文件本体。
3. 恢复时，在“数据与设置”点击“导入备份”，选择 JSON 备份并确认。
4. 导入会替换当前资料和文件。恢复前请先备份当前资料；取消操作或选择无效文件不会替换现有数据。

建议定期将备份复制到应用数据目录之外的位置或其他磁盘。备份文件可能因为其中的资源文件而较大。

## 数据、联网和隐私

- 桌面版的资料仅保存在这台电脑当前 Windows 用户的 `%APPDATA%\拾游` 应用配置中。文字记录和设置使用本地浏览器存储，文件本体使用本地 IndexedDB。
- 浏览器版资料保存在当前浏览器配置和当前网站来源中；`file://`、`http://127.0.0.1:8765` 和桌面版之间互不共享存储。
- 日常浏览、编辑、搜索、收藏、资源导入/下载及备份恢复不依赖网络。只有主动点击哔哩哔哩视频信息识别时，应用才会请求对应公开视频的公开信息。
- 应用没有账号、云同步或云数据库。清理浏览器站点数据或桌面应用数据可能删除本机资料，请用完整备份恢复。

## 开发检查

在项目目录安装 Node.js 后运行：

```powershell
node --test
```

该命令运行项目的单元、备份恢复、离线服务器和界面行为测试。
