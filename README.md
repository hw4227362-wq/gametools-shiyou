# 拾游 · 游戏攻略档案

个人使用的离线游戏攻略资料库。无需登录、账号或云服务。

## 启动

双击 `启动拾游.bat` 可启动 Windows 桌面版（构建后优先打开 `release/拾游-win32-x64/拾游.exe`）。桌面版使用独立的本地浏览器资料目录，核心功能仍在本机运行。若电脑已有浏览器版资料，可在浏览器版的数据与设置中导出完整备份，再在桌面版导入。

首次构建桌面软件时，安装 Node.js 24 或更新的 LTS 版本，双击 `构建拾游软件.bat`。构建结果位于 `release/拾游-win32-x64` 文件夹，文件夹可整体拷贝或压缩备份，运行其中的 `拾游.exe` 即可启动。构建依赖首次下载 Electron 运行时。

如果尚未构建桌面版，`启动拾游.bat` 会使用原来的本地服务，在默认浏览器打开网页版。服务只监听 `127.0.0.1`，不会向局域网或互联网开放。也可以直接打开 `index.html`，但 `file://` 和 `http://127.0.0.1:8765` 是不同的浏览器来源，会形成各自独立的本地资料库；切换时请通过完整备份迁移。

## 功能

- 首页：可按游戏名、资料标题、分类、标签和笔记搜索本地游戏分区、视频、文字攻略、资源及版本记录；同时展示统计、个人本地热点与最近整理内容。
- 游戏分区：按游戏归档视频、文字攻略、资源和版本记录；可导入、替换或移除 JPG、PNG、WebP 背景图，图片会压缩保存在本机并包含在完整资料备份内。
- 视频攻略：在详情窗口内嵌哔哩哔哩播放器；直接 MP4、M4V、WebM、OGG 文件链接使用浏览器原生播放器，其他网页地址会显示暂不支持提示，不会跳转来源页。
- 视频攻略：登记视频来源、时长及个人时间点笔记；粘贴哔哩哔哩公开视频链接后，可主动点击按钮识别标题、作者、时长和来源。
- 文字攻略：撰写和阅读自己的攻略笔记。
- 资源下载：将文件复制进浏览器本地资料库，或登记已有路径/链接；可下载已保存的文件。
- 收藏夹：集中查看收藏的攻略、视频和资源。
- 版本预览：整理版本改动、标签和待体验/已整理状态。
- 数据与设置：导出或导入 JSON 备份、管理显示偏好。

文字资料写入当前应用浏览器配置的 localStorage，文件本体写入 IndexedDB。桌面版配置保存在 `%APPDATA%\拾游`；完整 JSON 备份包含文字资料和文件本体，恢复时一并还原。建议把导出的备份另存到其他磁盘；清理应用数据会移除本机资料。首页热点和版本资料不会联网刷新，需要手动整理。视频自动识别只在用户点击后查询哔哩哔哩公开视频信息；不使用登录信息，其他功能仍可离线使用。

## 开发检查

在项目目录运行 `node --test`，可执行全部单元、数据恢复、离线服务器和界面行为检查。测试使用 Node.js 自带测试运行器，不需要安装第三方依赖。
